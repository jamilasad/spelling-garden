## Arabic: full harakat added
Every Arabic word now has full harakat, case endings and tanween, like the earlier list (وَالِدٌ). Wherever the sheet shows a haraka, it is kept exactly. These are the choices worth checking:

| On the sheet | In the app | Why it's worth a look |
|---|---|---|
| عمر | عُمْرٌ (age) | Listed next to سَنَة (year), so taken as "age". If it means the name Umar, it is عُمَرُ. |
| عشر | عَشْرٌ (ten) | Taken as written. Some books teach ten as عَشَرَةٌ. |
| نَظَارَة | نَظَارَةٌ | Usually written with a shadda: نَظَّارَةٌ. The sheet has none, so none was added. |
| بَرَايَة | بَرَايَةٌ | Everyday usage is بَرَّايَةٌ; standard Arabic is مِبْرَاةٌ. |
| مَحَايَة | مَحَايَةٌ | Everyday usage is مَحَّايَةٌ; standard Arabic is مِمْحَاةٌ. |
| الثَّلَاثَاء | الثَّلَاثَاءُ | The sheet has fatha on ث; dictionaries give الثُّلَاثَاءُ (damma). |
| الإِثْنَيْن | الْإِثْنَيْنِ | Kept with hamza as printed; the standard spelling is الِاثْنَيْنِ. |
| مِنْ فَضْلِك | مِنْ فَضْلِكَ | كَ is for speaking to a boy; to a girl it is فَضْلِكِ. |
| أَيَّة | أَيَّةُ (which, feminine) | |
| مئة | مِئَةٌ | Also written مِائَةٌ in older books. |
| السَّبْت، | السَّبْتُ | The comma on the sheet was dropped. |

To change any of these, tell Claude Code the word and the spelling you want. The audio, keyboard and checking follow the word automatically.
