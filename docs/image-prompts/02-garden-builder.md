# 02 · Garden builder ⭐ (do this file first)

These are the things she buys with honey and **drags anywhere in her own garden**. Make them in order: each step is a group, and the first steps matter most.

## Garden rules (paste once, before Step 1)
```
For the next images, add these GARDEN RULES to the style bible:
- Each image is ONE garden object that will be dragged around a cartoon garden.
- Front view, very slightly from above, as if it stands on flat ground in a cartoon garden.
- The bottom of the object touches the bottom of the canvas, centred, and the object fills about 85% of the canvas.
- No ground patch under it, no grass around it, no shadow, nothing else in the picture. Transparent background.
- Animals in this set may have simple cute faces (dot eyes and a small smile). Plants and objects still have no faces.
- No text, letters or numbers.
Reply "OK" and wait.
```

Sizes: **Square** = 1024×1024 · **Tall** = portrait 2:3 (1024×1536) · **Wide** = landscape 3:2 (1536×1024)
