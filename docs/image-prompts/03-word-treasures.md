# 03 · Word treasures (free rewards for blooming words)

When one of her words starts **blooming** (mastered), she wins a matching item for her garden **for free**. The garden then shows exactly which words she has learned.

Use the **garden rules** from `02-garden-builder.md` (paste them again if this is a new chat).

**Already covered by file 02** (no extra image needed):
- *mango* → `tree-mango`
- কাঁঠাল → `tree-jackfruit`
- ব্যাঙ → `visitor-frog`
- দোয়েল → `visitor-doyel`
- টগর ফুল → `plant-tagar`
- *river* → `water-stream`

Words with no sensible object (for example *estimate*, *spill*, মঙ্গলবার) give a mystery flower instead.
